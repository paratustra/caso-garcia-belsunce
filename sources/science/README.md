# INDICE de referencias científicas y técnicas

Elaborado el 2026-10-27. Alcance: avances 2015-2026 aplicables al reexamen de la evidencia física del caso García Belsunce. Las copias locales son solo versiones de acceso abierto (PMC Open Access Subset en AWS, arXiv, sitios oficiales). Las referencias de pago figuran con DOI y sin archivo. Los metadatos (autores, año, DOI) se verificaron contra Europe PMC o Crossref; donde dice "no verificado" no se pudo comprobar. Carpeta de PDF: `sources/science/pdf/`. Páginas web guardadas: `sources/science/web/`.

Abreviaturas: AA = acceso abierto; FSIG = Forensic Science International: Genetics; FSI Synergy = Forensic Science International: Synergy.
